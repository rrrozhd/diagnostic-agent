# Overconfident or prescriptive wording banned by spec section 7.
# One Python regex per line, searched case-insensitively in app-produced text only
# (never in source titles, excerpts, urls or ids: those are quotes). Comment lines start at column 0.
# Lines are stripped on load, so patterns use \b and \s, never leading or trailing spaces.
#
# Hedging decision: only the finite forms "rules out" / "ruled out" are banned. The base form
# "rule out" is left alone because it is how hedged text reads ("would help rule out",
# "to rule out", "cannot rule out"). "ruled out" and "confirmed" are allowed after hedging or
# negating words (be, not, not been, yet, until, if, once, unless), so "cannot be ruled out" and
# "has not been confirmed" pass while "has been ruled out" and "was confirmed" hit. Hyphenated terms like "laboratory-confirmed" pass.
# "the patient has" is allowed when it restates history ("has a history of", "has no", "has known").
\bthe\s+(final\s+|definitive\s+)?diagnosis\s+is\b(?!\s+(not|uncertain|unclear|undetermined)\b)
\bconfirms\b
(?<!\bbe\s)(?<!\bnot\s)(?<!\bnot\sbeen\s)(?<!n't\sbeen\s)(?<!\byet\s)(?<!\buntil\s)(?<!\bif\s)(?<!\bonce\s)(?<!\bunless\s)(?<!-)\bconfirmed\b
\brules\s+out\b
(?<!\bbe\s)(?<!\bnot\s)(?<!\bnot\sbeen\s)(?<!n't\sbeen\s)(?<!\byet\s)(?<!\buntil\s)(?<!\bif\s)(?<!\bonce\s)(?<!\bunless\s)\bruled\s+out\b
\bdefinitive(ly)?\b
\bdefinitely\b
\bthe\s+patient\s+has\b(?!\s+(a\s+)?(history|known|documented|reported|recorded|prior|previous|no|not)\b)
\byou\s+(should|must|need\s+to)\s+prescribe\b
\bcertainly\b
\bundoubtedly\b
\bwithout\s+(a\s+|any\s+)?doubt\b
\b100\s*(%|percent\b)
